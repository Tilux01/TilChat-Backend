# TilChat Backend

Early backend work for the TilChat messaging project.

## About

The first server version for TilChat, where the chat architecture was shaped before the final API backend took over.

## Features

- Initial chat server setup
- Socket based messaging experiments

## Tech Stack

- Node.js
- Socket.io
- Shell

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
